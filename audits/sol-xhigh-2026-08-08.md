## CRITICAL findings (4)

- **D01 — Next refresh deterministically writes an invalid all-zero-context catalog, then build fails.**
  `scripts/lib/aa-api.mjs:90` emits `context_length: 0` for "unknown"; the build validator
  rejects `context_length <= 0`. Verified: an in-memory refresh over committed snapshots yields
  119/119 product rows with `context_length: 0` → `Error: context_length is required and must be positive`.
  The first cron refresh after any fix overwrites the valid draft and breaks the build.
- **D02 — Canonical refresh can replace the catalog with `[]` and exit 0.** A renamed/missing
  response field collapses to `[]`; the row-count shrink guard runs only *after* the destructive,
  non-atomic write. A killed process can also leave truncated JSON on disk.
- **M001 — One finite-but-extreme metric (e.g. `Number.MAX_VALUE`, or literal `Infinity`) hard-freezes
  the default stage.** `hasMappedAxes()` rejects NaN but not other non-finite values; the log padding
  `MAX * 10^(…)` becomes `Infinity`, so `niceLogTicks()` loops `e0..Infinity` synchronously and never
  returns. A single bad catalog value = permanent tab freeze.
- **U01 — Reflected XSS via `?families=`/`?fam=` → `readout.innerHTML`.** `console.ts:700`
  interpolated `state.filters.families[0]` unescaped while every other interpolation in the file uses
  `escapeHtml()`. Payload `<img src=x onerror=…>` executes on first paint from a crafted share link.
