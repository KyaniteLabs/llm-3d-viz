**Auditor:** GLM 5.3 (orchestrator + heuristic pass) · **Vision critic:** kimi k3 (`kimi -p`, analysis-only)

## Verdict: CONDITIONAL PASS — 0 CRITICAL / 4 HIGH / 8 MEDIUM / 5 LOW

The 08-09 visual baseline holds (the stage itself renders beautifully and the design system is faithfully implemented), but UX-beyond-visual has real gaps: the mobile stage is undecodable, the default-view legend is a scroll trap, Decide's copy contradicts its own output, and several a11y/interaction details are dead or buried. Nothing blocks shipping to the private audience; items H1–H3 should land before any public/OSS push.

## Findings (CRITICAL → LOW). Each: evidence + fix.

### HIGH

**H1 — Mobile stage is undecodable as data.**
Evidence: axis titles/ticks suppressed under 640px (`src/viz/stage3d-three.ts:728` — "suppress domain titles/ticks on mobile — they clip"); entire legend hidden (`src/styles/tokens.css:720` — `.stage-guide { display: none }`); axis remapping UI hidden (`tokens.css:706`); task charts + score table hidden (`tokens.css:703`). DESIGN-SYSTEM.md:49 law: "Legend HUD open by default… decoding must not require hover on marks" — violated on phones. Kimi + my vision pass agree: "colored balls, no axes". The console bottom sheet still carries rankings (rescues it from CRITICAL).
Fix: a mobile legend chip (collapsed "KEY" pill → bottom-sheet legend reusing StageGuide sections) + restore 2 ticks/axis or corner axis-labels ("$/M · IQ · tok/s") drawn once outside the clip zone; alternatively surface the projection strip properly (currently 3 charts in 5.5rem, one column).

**H2 — Stage-key scroll trap: the "open by default" legend shows 12% of itself.**
Evidence: probe — body clientHeight 288px vs scrollHeight 2302px, no visible scrollbar affordance; both vision critics read the panel as "cut off" (04 kimi claim confirmed). Encoding, lab colors, glyphs, intelligence anchors, frontier list all live in this one collapsed-by-size region floating over the stage (guide rect x931–1155 overlays the canvas).
Fix: give the guide a max-height + visible slim scrollbar + a "+N more" affordance; or split: ENCODING+GLYPHS compact and pinned, LAB COLORS/FRONTIER in a secondary collapsed section.

**H3 — Decide copy contradicts Decide output ("shortlist of 3" vs "2 of 2").**
Evidence: `src/ui/decide-panel.ts:45` — "…shortlist of 3 follow the cheap↔fast bias"; actual header `decide-panel.ts:341` — "SHORTLIST · 2 of 2 on ridge · 31 eligible" (probe-confirmed live). The variable-length logic is correct (ridge-sized shortlist); the static marketing sentence is wrong. In a decision tool this is a trust hit (kimi called it critical; I rank HIGH since logic is sound and self-explaining).
Fix: dynamic blurb — "shortlist follows the ridge (top 3 max)" — and reuse the single-model note pattern at :320-322 for the 2-model case.

**H4 — Landing information density: the answer doesn't out-shout the instrument.**
Evidence: right rail stacks SELECTION → STAGE KEY (floating mid-stage) → SCORE → GOAL ("What are you optimizing for?") → 8 intent cards → weight sliders → Advanced → NAVIGATE + 24 chips; stage adds 4 task callouts + focus-set direct labels + 2D strip + status bar. Both critics independently counted 7+ equal-weight typographic blocks; "Gemini 3.7 Flash" (the top pick, story line `main.ts:521-528`) has no more presence than any chrome block.
Fix: after the first preset click, collapse GOAL to a one-line "Goal: Best balance ▸ change"; move STAGE KEY off the stage into the console top (or a toggle); consider hiding task callouts until a mark is selected.

### MEDIUM

**M1 — Cinema button state is never announced (dead a11y sync).**
Evidence: `src/ui/console.ts:881-885` queries `[data-cinema-toggle]` inside the console root, but the button lives in the header (`index.html:141`) — label swap ("ENTER/EXIT CINEMA") and `aria-pressed` sync are dead code; no other sync exists (grep: only main.ts:427 click binding). `aria-pressed` stays "false" forever.
Fix: move the sync into main.ts's store.subscribe next to the decideToggle sync (`main.ts:445-450`).

**M2 — Escape doesn't close the filter shelf; it resets scope instead.**
Evidence: global handler `src/main.ts:839-847` — Esc exits cinema, else calls `consoleUi.showAllFamilies()` (clears family solo + pin). FilterShelf has no keydown handling (grep: none) — with the shelf overlay open, Esc mutates the visible set instead of dismissing the overlay.
Fix: Esc ordering: cinema → filter shelf → family solo. Close the shelf in `setScopeOpen`'s keydown or a shelf-local Escape listener.

**M3 — Global search: Enter-only, silent failure.**
Evidence: `src/main.ts:462-477` — only Enter triggers; on no match, nothing happens (no status, no suggestion); no `/` focus shortcut; pin feedback is indirect.
Fix: aria-live "No match for X" on miss; top-5 dropdown as-you-type; `/` focuses search.

**M4 — Cinema mode's atlas remnant reads as a rendering bug.**
Evidence: `tokens.css:630` keeps `.atlas-dock` at opacity 0.25 / scale 0.85 / max-height 1.5rem with hover-restore 0.7 — unreadable text bottom-right in a presentation mode (probe-confirmed). Intent is detune; effect is "broken".
Fix: collapse to a monogram dot ("ATLAS ◈") that expands on hover, or hide entirely in cinema.

**M5 — Keyboard shortcuts are undiscoverable; `S` export is secret.**
Evidence: `[ ] , . Esc C` documented only in a collapsed `<details>` (`src/ui/console.ts:350-351`); cinema frame export `S` (`src/main.ts:403-408`) appears nowhere in UI copy.
Fix: add `S` to the keys line; a one-time "?"-hint chip or help overlay; titles on scope-bar buttons.

**M6 — `role="tablist"` without tab keyboard semantics.**
Evidence: `index.html:159-163` mode tabs use tablist/tab; click-only handling (`main.ts:302-312`), no arrow-key roving tabindex (WAI-ARIA tabs pattern).
Fix: implement arrow-key activation or downgrade to `role="radiogroup"`/plain buttons with `aria-pressed`.

**M7 — Mobile micro-type and flush scroll boundary.**
Evidence: status bar 0.625rem (10px) nowrap + ellipsis (`tokens.css:726`); effort strip 0.625rem (`:727`); console sheet bottom edge is flush with status bar (probe: 789.22 == 789.22) — no fade/mask, so mid-glyph slicing perception at scroll ends. Contrast is fine (computed: `--text-muted` #89939E on #070C0B ≈ 6.3:1, passes AA — kimi's "sub-contrast" claim is really a size problem).
Fix: 11px floor for status/effort text; add a scroll fade mask on the console sheet bottom.

**M8 — Decide mini-chart a11y + bias readout.**
Evidence: chart dots are `<circle><title>` only — not focusable, tooltip hover-only (`decide-panel.ts:292`); bias slider shows no numeric output anywhere (`decide-panel.ts:60-65`), unlike the floor slider which has `<output>`.
Fix: `tabindex="0"` + `aria-label` per dot (or a "table view" toggle reusing membership-table); `<output>` for bias showing "cheaper 60% ←" style text.

### LOW

**L1** — Nav stepper buttons `◀`/`▶` expose glyph text to SRs, tooltip-title only (`console.ts:306-321`). Add `aria-label="Previous family"` etc.
**L2** — Touch floor 2.25rem = 36px (`tokens.css:1858,1886,1896`) vs 44px Apple HIG recommendation. Bump primary controls to 44px.
**L3** — "Copy decision" copies raw JSON without saying so (`decide-panel.ts:183`). Label: "Copy decision (JSON for agents)".
**L4** — Cinema deliberately unavailable on mobile (`tokens.css:1890`). Fine, but the Cinema [C] key handler still fires on phones with keyboards; consider a mobile toast.
**L5** — Stage hover tooltip (`role="status"`, `console.ts:167-171,964-977`) follows cursor only; keyboard pinning doesn't reposition it near focus.

## What's notably GOOD (beyond the 08-09 visual baseline)

- First-load comprehension spine: story line ("Top pick… Gemini 3.7 Flash…"), GOAL prompt with 8 intent presets + local-VRAM intents that re-scope correctly, intelligence task anchors ("what work looks like") — a newcomer has a path (`main.ts:521`, `console.ts:100-107`, `stage-guide.ts:153-171`).
- Decide mode flow: teaches the floor plane in one paragraph, hides explore chrome, anchor keeps "out of scope" option labeled, real empty states at every level (`decide-panel.ts:42-46,251,317`, `console.ts:804-822`).
- Error/empty coverage: boot-fail banner, boot-blank guard, deferred-chunk failure boundary, empty-visible banner with recovery tips (`main.ts:136-174,318-331,893-905`).
- A11y engineering: global `:focus-visible` copper outlines, `prefers-reduced-motion` global kill + cinema auto-exit (`tokens.css:129,736`, `cinema.ts:41-50`), score-table rows keyboard-activatable (`console.ts:943-956`), visually-hidden h1 kept on mobile (`tokens.css:1834-1845`), canvas aria-labels that narrate mode (`stage3d-three.ts:1374-1378`).
- Reduced-motion and reduced-viewport paths were clearly designed, not bolted on.
